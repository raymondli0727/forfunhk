# 熊本7.1級地震死咗人，香港人竟然照去日本？日本旅遊仲安全嗎？🇯🇵💥

## 🌊 開場：今朝起身俾個地震嚇親

喂喂喂，各位香港朋友，今日（7月29日）一早就俾個重大新聞嚇醒咗。

**日本熊本縣發生咗7.1級強烈地震。** 😱

冇錯，就係嗰個熊本——即係有熊本熊嗰個熊本。今次地震嘅震央位於熊本縣嘅益城町附近，深度大約10公里，屬於淺層地震，破壞力極強。

截至而家嘅消息：

- **至少2人死亡**
- **多人受傷**
- **部分建築物倒塌**
- **嘉島町有商場爆炸**
- **日本政府已調派自衛隊參與救援**

但係最令我震驚嘅，唔係地震本身，而係之後睇到嘅一條新聞——

> **「熊本發生7.1級地震後，有港人如常出發去日本旅行」**

吓？死咗人喎，仲照去？🤯

今日呢篇文章，就想同大家傾吓呢個現象：**點解香港人對日本地震「免疫」？日本旅行仲安唔安全？我哋應該抱咩心態去面對？**

## 📋 事件重溫：熊本7.1級地震有幾嚴重？

先同冇追開新聞嘅朋友講吓今次地震有幾誇張。

### 地震基本資料

| 項目 | 內容 |
|------|------|
| **發生時間** | 2026年7月29日凌晨 |
| **震央** | 日本熊本縣益城町 |
| **震級** | **7.1級** |
| **深度** | 約10公里（淺層地震） |
| **最大震度** | 7弱（日本氣象廳震度階級） |
| **死亡人數** | 至少**2人** |
| **受傷人數** | 多名（數字持續更新中） |
| **建築損毀** | 多處房屋倒塌、道路中斷 |
| **特殊事件** | 嘉島町商場爆炸 |

7.1級係咩概念？**1995年嘅阪神大地震係7.3級**，當年造成6,434人死亡。雖然今次地震冇當年咁嚴重，但係7.1級絕對唔係「小兒科」。

### 最新情況

根據RTHK報導，日本政府已經**調派自衛隊參與救援**。嘉島町一個商場仲發生咗爆炸，造成兩死，情況都幾嚴峻。

而香港方面，**Yahoo新聞**同**多個媒體**都有報導，部分身在九州嘅港人感受到輕微震動，有啲人甚至喺機場感受唔到地震——但知道消息之後都表示擔心。

## ✈️ 香港人「照去日本」嘅現象

好喇，嚟到最有趣嘅部分。

新聞報導指出，**即使熊本發生7.1級地震，仍然有港人如常出發去日本旅行**。

呢個現象，其實好值得我哋思考。

### 點解香港人會照去？

我歸納咗幾個可能嘅原因：

#### 1️⃣ 「慣咗」 — 日本成日地震

老實講，日本本身就好多地震。香港人成日去日本，對「日本有地震」呢個消息已經有啲麻木。**過去幾年，熊本地區前前後後都震過好多次**，今次雖然係7.1級比較大，但係對好多「老手」嚟講，覺得「邊有咁啱得咁橋呀」。

#### 2️⃣ 行程一早plan好，好難改

去日本旅行唔係去深圳咁簡單，機票、酒店、請假——**全部plan好哂**。尤其係暑假旺季，好多香港人一家大細早就book好哂，突然取消嘅成本好高。

「唔通因為九州地震就成個行程取消？我去東京喎。」

呢種心態好常見。事實上，今次地震嘅主要影響範圍係**九州中部（熊本、大分一帶）**，如果行程係去東京、大阪、北海道，邏輯上嘅確冇直接影響。

#### 3️⃣ 資訊不對稱

雖然香港媒體有報導，但係**唔係人人都會仔細睇地震新聞**。有啲人可能淨係知道「日本有地震」，但唔知有幾嚴重，照樣出發。

#### 4️⃣ 「死就死啦」嘅香港精神

唔好否認，香港人出名大膽，尤其係面對「同自己生活冇直接影響」嘅事情。**「人哋話有地震啫，我上次去都冇事啦。」**

呢種心態好香港——有啲似香港人行山掛8號風球都要衝嘅精神 😂

## 🔍 我嘅分析：照去其實有冇問題？

講真，我唔想一刀切話「去係啱」或者「唔去係錯」。呢個問題要分幾個層面睇：

### 如果行程係九州

呢個係最需要認真考慮嘅情況。

如果你plan咗去**熊本、福岡、大分、長崎**呢啲九州地區，我建議你：

- **Check航空公司嘅取消/更改政策** — 好多航空公司喺呢啲情況下會提供免費改期
- **留意日本氣象廳嘅餘震預警** — 7.1級地震之後通常會有餘震，甚至可能再有大震
- **聯絡酒店確認情況** — 睇吓酒店有冇受損，附近交通係咪正常
- **購買旅遊保險** — 如果你未買，而家都仲可以買（不過地震相關可能唔保）

**個人建議：** 如果行程係熊本、益城町一帶，真心建議延期。但如果係福岡、長崎等遠離震央嘅地方，而又check清楚交通冇問題，可以考慮照去，但係要提高警覺。

### 如果行程係東京/大阪/北海道

坦白講，影響真係唔大。

香港距離九州都成2,500公里，而東京距離熊本更加係接近900公里。**從地理上嚟講，東京、大阪、北海道唔會受到熊本地震嘅直接影響。**

但係你要留意嘅係：

- **日本全國鐵路可能會有安全檢查導致延誤**
- **部分航班可能因為調配救援資源而有變動**
- **心理上——你玩得安心嗎？**

### 我個人嘅立場

我唔會話「照去日本嘅人好自私」或者「取消行程嘅人好怕死」。

每個人對風險嘅承受能力唔同，**最緊要係知情嘅情況下做決定**。

如果你知道自己去嘅地方安全、買足保險、做好應變計劃，咁照去其實冇問題。但如果你係「是但啦，死就死」嗰種心態——咁我就不太認同。

2011年東日本大地震嘅時候，香港人真係好驚，訪日人數大跌。但係到咗2024年能登半島地震，影響已經好輕微。

點解？因為香港人去日本實在太頻密，**日本旅行已經成為咗香港人生活嘅一部分**。邊個會因為「某個地方有地震」就放棄自己plan好咗嘅旅行？

## 💭 深度分析：香港人對日本嘅「情意結」

其實今次呢個話題，觸及到一個更深層次嘅問題——**香港人同日本嘅關係。**

### 香港人點解咁鍾意日本？

唔使我多講，大家都明：

- **地理位置近** — 4個鐘機程，放假可以去
- **文化相近** — 日本嘢香港人由細睇到大
- **食物好食** — 日本嘢食冇得輸
- **購物天堂** — 日圓低水，買到盡
- **服務質素好** — 日本服務態度冇得彈
- **治安好** — 全世界最安全嘅國家之一

根據日本政府觀光局嘅統計，**2025年香港訪日旅客超過250萬人次**，即係平均每個香港人去咗超過3次日本。

日本對香港人嚟講，已經唔係「外國」，而係**第二個家**。

### 「照去」反映嘅香港人特質

我成日覺得，香港人有種好特別嘅 mentality：

> **「你話危險？我先唔信。我睇過、我行過、我試過——我話事。」**

呢種「自主判斷」嘅精神，好有香港特色。香港人唔會因為媒體報導就改變自己嘅計劃，而係會自己去搜集資訊、評估風險，然後做決定。

呢件事本身係好嘅——獨立思考嘛。但係另一方面，**過度自信同輕視風險**，都可能係問題。

### 平衡點喺邊？

我覺得最好的態度係：

1. **了解資訊** — 睇清楚地震嘅實際影響範圍
2. **評估風險** — 你嘅行程係咪真係受影響？
3. **做好準備** — 買保險、plan應變方案
4. **保持靈活** — 如果情況變差，要識得「轉軚」
5. **尊重他人決定** — 有人取消行程係合理嘅，有人照去都係合理嘅

## 💡 實用貼士：如果決定照去日本，要注意咩？

俾各位準備出發或者已經喺日本嘅朋友一啲實用建議：

### 出發前

- ✅ **Check日本氣象廳官網** — 睇最新地震資訊同警報
- ✅ **下載安全App** — 例如「Safety tips」（日本觀光廳官方App）
- ✅ **買足旅遊保險** — 確保有包「自然災害取消/中斷」
- ✅ **通知親友行程** — 等家人朋友知你喺邊
- ✅ **影低護照等重要文件** — 電子版放手機

### 到達後

- 🏨 **入住時問清楚逃生路線** — 酒店通常有地震指引
- 📱 **保持電話有電** — 帶定「尿袋」
- 🚃 **留意交通公告** — JR可能因為安全檢查 delay
- 🏪 **記低最近嘅避難所位置** — 日本每個社區都有指定避難所
- 🌊 **如果你喺沿海地區** — 留意海嘯警報

### 萬一遇到地震

日本政府同觀光機構有清楚指引：

1. **Drop! （低く）** — 趴低
2. **Cover! （身を守る）** — 保護頭部
3. **Hold on! （動かない）** — 等到震動停止
4. 跟從指示去避難所
5. 聯絡入境港府或領事館（如果需要的話）

## 🌏 更宏觀嘅反思

最後，我想講多少少宏大嘅話題。

### 氣候變化同自然災害

其實近年日本嘅大型自然災害愈嚟愈頻密——地震、颱風、暴雨、山泥傾瀉。**呢個唔單止係日本嘅問題，而係全球性嘅問題。**

2026年已經發生咗幾次大型颱風影響香港（仲記唔記得颱風紅霞？颱風白海豚？），而家又輪到日本大地震。

地球先生似乎愈嚟愈唔正常。🌍

### 旅遊嘅責任

我去旅行嘅時候，成日諗一個問題：**我係遊客，但係我同時都係一個「外來者」。**

如果當地發生咗災難，我仲應唔應該去？

有人話：「我去旅行可以帶動當地經濟，幫到佢哋復甦。」呢個講法喺某程度上係合理嘅——2011年東日本大地震之後，好多人去東北旅遊就係為咗「支援復興」。

但係另一方面，如果你嘅出現會**消耗當地嘅救援資源**（例如你受傷要人救、阻住咗救災通道），咁就唔係幾好。

**關鍵係：你有冇能力照顧自己？**

如果你準備充足、買足保險、唔會成為別人嘅負擔，咁你嘅「照去」係負責任嘅。但如果你係「風景照打卡最重要，其他嘢冇所謂」——咁就真係唔該諗清楚。
